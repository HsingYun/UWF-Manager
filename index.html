Overlay configuration and HORM

Configure overlay storage, inspect its files, and verify the prerequisites for HORM.

Overlay settings

Set overlay type, capacity, usage thresholds, persistence, and supported operating modes.

Overlay file browser

Browse and filter overlay files, export the list, and use available commit actions.

HORM: Hibernate Once, Resume Many

Resume the same saved hibernation state on subsequent starts. Inspect HORM prerequisites and stage enable or disable operations for review.

Checks cover current UWF protection, the RAM Read-Only Media configuration, full S4 hibernation, and protection of eligible mounted fixed volumes. After enabling HORM, hibernate once to save the baseline.

While HORM is active, configuration changes, individual commits, automatic staged-file commits, and full volume commits are unavailable. Disable HORM and restart before maintenance.

Configuration import and review

Command import

Import supported uwfmgr commands into a configuration draft and inspect validation results. Import does not execute commands.

Configuration review

Review pending changes, execution requirements, and exportable uwfmgr commands before applying a configuration.

03

File staging and enhanced mode

Maintain a list of files to commit and choose how commits are handled before shutdown or restart.

File staging

Stage files and directories for commit before a safe shutdown or restart initiated from the application.

Optional enhanced mode

Use a Windows service to commit eligible staged files before system shutdown or restart.

Selective commits

Commit selected files or registry items and inspect the result for each item.

Available operations depend on the current protection state and UWF configuration. Review the selected scope before execution.

Runtime status

View filter status and overlay usage in the taskbar or floating panel.

System requirements

Operating system
Windows 10 / 11 Enterprise, Education, or IoT Enterprise, including applicable LTSC editions.
Windows feature
Unified Write Filter installed and enabled as a Windows optional feature.
Permissions
Administrator privileges for the graphical interface and protected command-line operations.
